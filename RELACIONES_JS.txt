====================================================================
  MAPA DE RELACIONES ENTRE ARCHIVOS JS — Voto Electrónico v11
====================================================================

Cómo leer este documento
-------------------------
Cada página HTML ahora carga UN SOLO <script type="module"
src="js/paginas/<pagina>/entry.js">. Ese entry.js es el punto de
partida: importa (con "import") los demás archivos de su carpeta, que
a su vez importan piezas compartidas de js/supabase/ y js/utils/.

"A depende de B" significa que A tiene una línea "import ... from B"
en la parte de arriba del archivo.

Todos los archivos usan ES Modules (import/export). Las funciones que
el HTML llama con onclick="..." (por ejemplo onclick="eliminarLista(5)")
se exponen explícitamente con una línea window.nombreFuncion =
nombreFuncion al final del archivo que las define — así el HTML no tuvo
que tocarse casi nada.

1. ARCHIVOS COMPARTIDOS (los usa más de una página)
====================================================================

js/supabase/config.js
  - Contenido: SUPABASE_URL y SUPABASE_ANON_KEY.
  - Lo usa: js/supabase/client.js.

js/supabase/client.js
  - Depende de: config.js, y de window.supabase (librería @supabase/
    supabase-js, cargada con <script> normal en el <head> de cada
    página, ANTES del <script type="module">).
  - Exporta: supabaseClient (la conexión).
  - Lo usa: prácticamente todos los módulos de todas las páginas.

js/supabase/auth.js
  - Depende de: client.js.
  - Exporta: obtenerPerfilActual, requireAdminSession,
    requireResultsSession, cerrarSesion.
  - cerrarSesion se expone en window (todas las páginas administrativas
    tienen un botón "Cerrar sesión" con onclick="cerrarSesion()").
  - Lo usa: el entry.js de CADA página protegida (todas menos
    index.html y votar.html, que son públicas).

js/supabase/navegacion.js
  - Depende de: auth.js (obtenerPerfilActual).
  - Exporta: ajustarNavegacionPorRol (oculta enlaces solo-admin y
    cambia la etiqueta de rol en el menú para un directivo).
  - Lo usa: dashboard/entry.js, resultados/entry.js.

js/supabase/storage.js
  - Depende de: client.js.
  - Exporta: subirImagen (sube un archivo al bucket público "media").
  - Lo usa: configuracion/insignia-form.js, listas/listas-crud.js,
    listas/candidatos-crud.js.

js/supabase/colegio.js
  - Depende de: client.js.
  - Exporta: cargarColegioPublico (pinta nombre/lema/insignia del
    colegio; no requiere sesión).
  - Lo usa: index/entry.js, votar/entry.js.

js/utils/html.js
  - Sin dependencias (función pura).
  - Exporta: escapeHtml (evita XSS al insertar datos en innerHTML).
  - Lo usa: casi todos los módulos que arman tablas/tarjetas con datos
    de Supabase.

13. Funciones expuestas en window (por qué existen)
====================================================================
El HTML original usa atributos onclick="..." tanto en botones fijos
del HTML como en botones generados dinámicamente por JavaScript
(dentro de un innerHTML). Los módulos ES no exponen sus funciones como
variables globales automáticamente, así que cada función llamada de
esa forma tiene una línea extra al final de su archivo:

    window.nombreFuncion = nombreFuncion;

Esto es SOLO "cableado" (conectar el HTML con el módulo) — no cambia
en nada la lógica interna de la función. Lista completa:

  cerrarSesion            → js/supabase/auth.js
  cambiarEstadoDirectivo  → js/paginas/usuarios/directivos.js
  revocarInvitacion       → js/paginas/usuarios/invitaciones.js
  nuevaLista               → js/paginas/listas/listas-crud.js
  editarLista               → js/paginas/listas/listas-crud.js
  eliminarLista             → js/paginas/listas/listas-crud.js
  abrirModalCandidato        → js/paginas/listas/candidatos-crud.js
  eliminarCandidato          → js/paginas/listas/candidatos-crud.js
  nuevaMesa                   → js/paginas/mesas/mesas-crud.js
  editarMesa                   → js/paginas/mesas/mesas-crud.js
  eliminarMesa                  → js/paginas/mesas/mesas-crud.js
  abrirModalMiembros              → js/paginas/mesas/miembros-mesa.js
  seleccionarLista                 → js/paginas/votar/paso-boleta.js
  exportarExcel                     → js/paginas/padron/excel-exportar.js

14. Cómo leer el proyecto por primera vez (sugerencia de recorrido)
====================================================================
1. js/supabase/config.js y client.js — cómo se conecta todo a Supabase.
2. js/supabase/auth.js — cómo se protege cada página (login, roles).
3. Elige UNA página completa y sigue su entry.js paso a paso, abriendo
   cada archivo que importa en el orden en que aparece.
4. Los archivos "estado.js" de cada página son un buen resumen de
   "qué información necesita recordar esta pantalla mientras el
   usuario la usa".
5. Los comentarios de cabecera de cada archivo (el bloque con "===")
   siempre dicen: qué hace el archivo, de qué depende, y quién lo usa.
